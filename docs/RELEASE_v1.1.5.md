发布者：RiverXILee。项目许可证：GNU GPL v3.0（GPL-3.0-only）。

2026-11-07 从预发布转为正式版，并设为最新版本。
本次沿用原有安装包、文件夹 ZIP 和校验值，不修改程序文件或移动构建标签。
液态玻璃整体 UI 改版延期，留待后续版本；本次保留现有界面。

## 下载选择

- x64-setup.exe：自定义安装界面，安装后为主程序与外置资源的多文件结构。
- x64-folder.zip：免安装文件夹版，必须完整解压，再运行其中的主程序；不能只复制 EXE。
- SHA256SUMS.txt：下载文件校验值。
- LICENSE 与 THIRD_PARTY_NOTICES.txt：项目许可与第三方依赖声明。

## 本次变化

- 主程序从 resources/web 读取实际界面文件，启动时检查资源版本和完整性，避免缺文件、损坏或版本混装。
- 设置采用分类目录和二级页面，快捷键可逐项清除并保存。
- 歌词流光演出、设置与字体选择器状态优化，保留纯净模式及减少动态效果。
- 进度线增加青蓝到薄荷绿渐变，控制条增加半透明底，小窗口仍保留进度线；歌词区域保持透明。
- 保留原有应用标识、用户配置、窗口位置、显示方案和歌词缓存的保存路径。
- 项目加入 GPL-3.0-only 许可，包内附项目许可与第三方声明。

## 测试边界与已知事项

- 已通过自动化测试、Windows 构建，以及 ZIP 解压和资源自检。
- 完整安装、覆盖升级、卸载、跨电脑与真实音乐客户端回归仍需人工验收。
- 独立新包的完整界面尚未获得可靠的自动化实机确认，整套 UI 精修也尚未全部完成。
- 安装前从托盘完全退出旧版；重复启动会唤醒已运行实例。

- 应用内更新仍使用安装包；若要保持文件夹版，请手动下载后续完整 ZIP。

- 暂无 Authenticode 代码签名；GPL 许可和 SHA-256 不代表 Windows“已验证发布者”。
