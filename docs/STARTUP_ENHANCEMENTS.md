# 首次启动与默认增强

日期：2026-11-25。适用 v1.2.0.2；此流程替代先前测试包设置页中的网易云/酷狗单独开启按钮。

## 用户流程

首次启动先展示统一风险说明，不初始化主界面、媒体轮询或自动增强。仅「同意并进入」会通过与窗口绑定的一次性确认回执，保存当前范围版本的授权。没有「取消后继续使用」选项：「退出应用」、Esc、关闭提示、超时或异常都不会按同意处理。

后续启动读取有效授权后进入，不重复首次提示。旧版仅为酷狗或网易云单独确认的记录不能替代本次统一授权。授权缺失、损坏或范围版本变化时重新确认；不使用 localStorage 作为后台授权依据。

## 默认开启的边界

- 授权后每 6 秒检测一次，设置页只显示状态，不再提供两个开启按钮。自动操作在后台串行执行，防止重复重启或写文件。
- 网易云已运行时，使用既有临时增强路径正常退出并重新启动；不修改其客户端文件。失败后本次应用运行中不再自动重试，避免反复打断音乐。
- 酷狗已由本测试配置准备时复用原有备份和恢复记录，不再打补丁。未准备且还在运行时提示先完全退出，不强杀进程；正常退出后再自动准备，随后由用户正常打开酷狗。
- 未安装、未识别或未运行的播放器不强行启动。酷狗未知内核、已有他方补丁、权限不足、恢复记录冲突或升级后的文件均按安全检查停止，不自动放宽限制或提权。

## 退出与撤回

退出桌面歌词不等于关闭音乐客户端的调试端口，也不自动恢复酷狗文件。托盘菜单「关闭增强并恢复」保留恢复入口，首次确认页也能从托盘进入，不必先同意默认增强。

明确确认恢复后先撤回默认授权并暂停后台操作，再恢复网易云普通启动模式与酷狗原文件，成功后退出应用。恢复前完全退出酷狗；网易云恢复会重启并暂时中断音乐。恢复失败保留备份和记录，给出再次恢复或退出入口。正常重新打开已恢复的播放器后，才关闭其本次增强端口。

## 更新日志

首次进入主界面后自动弹出当前版本日志，同一版本只提醒一次，随后仍可在「设置 → 关于与帮助 → 更新日志」重看。完整文案见 [CHANGELOG_NEXT.md](CHANGELOG_NEXT.md)，正式说明见 `RELEASE_v1.2.0.2.md`。

## 验证范围

自动化覆盖授权缺失/拒绝/异常退出、有效授权复用、确认范围版本与损坏记录、首次弹窗的退出/Esc/关闭行为，以及设置中不再存在开启按钮。实际首次授权、网易云自动重启、酷狗自动准备和撤回恢复需人工在候选包中验证；不会由助手代点安全授权，也不把编译通过等同于真实闭环通过。
