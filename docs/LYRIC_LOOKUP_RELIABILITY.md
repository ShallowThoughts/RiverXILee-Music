# 歌词匹配与缓存

产品名称不变，对外版本号 1.2.0.0、内部构建版本 1.2.0。这些改动随 v1.2.0.0 正式版交付；发布功能与验证边界见 RELEASE_v1.2.0.0.md。

- 自动缓存上限 1000 首，按最近使用淘汰；手动绑定不计入自动淘汰限额。保留原生 preferences.json 保存路径。浏览器配额不足不能清空内存与原生缓存。
- 匹配修订号 2 让已有带元信息的旧自动结果重新查询，手动版本选择保留；缓存记录播放时长，超过 6 秒的差异不复用自动结果。
- 两源仍并发。同平台有最多 4 秒优先窗口，失败、无匹配或超出等待窗口时使用合格备用结果。没有 QQ 精确歌曲 ID 的情况下仍是元信息搜索，不保证每首歌都绝对准确。
- 括号或后缀中的 Live、伴奏、翻唱、Remix、加速、慢速、不插电标记必须一致；已知时长差大于 6 秒拒绝自动候选。普通歌名中的 Live 等单词不直接当版本。
- HTTP 429/502/503/504 及对应 JSON 错误最多请求三次。支持短数字 Retry-After；长值或日期形式不在单次请求内立即重试。前端临时服务故障从 30 秒开始退避，支持返回的数字等待提示。
- 没找到歌词、响应为空、超时与 503 不等于纯音乐。仅明确版本标记、歌词源 nolyric 声明或整段歌词只有纯音乐提示时自动确认。
- 自动纯音乐确认缓存最多 7 天，使用缓存不顺延确认时间；可手动重试。用户手动标记不自动过期，可用「恢复自动匹配」撤销。
- 不做音频识别，因此没有标记的纯音乐可能仍需一次在线查询或手动标记；不承诺凭空判断所有纯音乐。

验证必须包括缓存保留、过期、手动优先、503 失败后恢复、同平台优先、录音版本排除，以及原有切歌过期请求隔离。模拟接口测试不能证明线上服务从此不再返回 503。

## 切歌恢复与译文

网易云 JSON 业务错误 405 在同一方法下只重试一次；不把 HTTP 405 当作可重试的 503，不伪造 Cookie 或绕过服务访问控制。首次快速失败有一次 650ms 恢复窗口，前端不立即转错误页；503/限流、超时、明确无匹配等不进入此快速恢复。持续失败仍可见，405 后续重试退避。

译文仅从选中版本的网易云 tlyric / QQ trans 读取。QQ 优先调用其公开网页使用的 GetPlayLyricInfo（同一 songMID、trans=1），解码原文与译文；请求失败或原文无效时回退旧歌词接口。旧接口返回空 trans 不代表播放器没有译文。开启双语时会重取旧版 QQ 自动缓存，带新译文修订标记的缓存不重复刷新；手动绑定保持不变，可重新指定同一歌词版本刷新。前端按原文时间戳在 750ms 容差内对齐，不替换原文字级时间；无译文、重复原文、占位符或无法对齐时保留原文。界面区分本次未取得与取得后未对齐，不宣称歌曲本身没有翻译。开关属于显示设置，随本地设置与显示方案保存。不是自由选择目标语言的机器翻译。
