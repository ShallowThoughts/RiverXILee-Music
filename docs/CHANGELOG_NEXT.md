# v1.2.0.2 更新日志

日期：2026-11-25。Windows 正式版，GPL-3.0-only。下载与风险说明见 `RELEASE_v1.2.0.2.md`。

## 更新日志提醒

- 每次升级后首次启动，自动弹出当前版本的更新日志；同一版本关闭后不重复提醒。首次安装也展示一次。
- 已读版本随原有原生配置保存，不清空字体、窗口位置、快捷键、歌词缓存或手动绑定。降级版本不会自动重复弹出。
- 「设置 → 关于与帮助 → 更新日志」可随时重看；首次增强风险确认先于主界面和更新日志，新手引导在日志关闭后再出现。

## 首次使用与默认增强

- 首次启动在主界面出现前，统一展示网易云增强与酷狗增强的用途、客户端重启、文件修改、数字签名及本机调试端口风险。
- 只有点击「同意并进入」才记录授权并进入主界面；「退出应用」、关闭提示、Esc、超时或确认失败均不视为同意。
- 同意后默认检测并准备两项增强，设置页移除各自的开启按钮，改为只读状态。未安装、未识别或未运行的播放器不强行启动。
- 酷狗若仍在运行且尚未准备，提示正常退出后再自动准备，不强杀客户端。网易云使用临时启动参数，不修改其文件。
- 托盘保留「关闭增强并恢复」：明确确认后撤回默认授权、恢复客户端并退出；恢复失败保留备份与说明。
- 无授权、授权记录损坏或版本不符时禁止自动操作；自动检测失败不会循环重启播放器或循环修改文件。

## 酷狗识别与歌词同步

- 修复本机调试端口由酷狗安装根目录启动器持有、却被旧版误判为非目标进程的问题。
- 只接受已确认安装中的启动器或对应版本进程，继续校验进程创建时间、当前登录会话和独占回环端口。
- 已在蔡健雅《红色高跟鞋》实播中观察到界面进度从 02:34 推进到 02:50、歌词显示行正常切换。
- 酷狗读取真实进度与录音 hash，歌词仅使用酷狗来源；普通 SMTC 没有时间轴时不从零估算。酷狗进度拖拽仍不支持。
- 保留完整原文件备份及 SHA-256 校验，拒绝用旧备份覆盖已升级或外部修改的酷狗文件。

## 歌词来源与版本匹配

- QQ、网易云、酷狗严格使用本平台歌词，失败后不跨平台回退；未接入自有歌词源的平台明确说明不可用。
- 在线候选、候选取词、缓存与手动绑定检查平台来源；保留本地导入与手动纯音乐标记。
- 结合歌手、专辑、时长与版本标记减少同名歌曲错配；识别到更准确的原生歌曲标识后刷新自动匹配，不覆盖用户手选结果。

## 风险及验证边界

增强并非无风险开关：酷狗需修改内核文件、原数字签名会失效；播放器调试端口可能被本机其他进程或网页访问。退出桌面歌词不会自动关闭仍在运行的播放器端口或恢复酷狗文件。用户可从托盘恢复入口撤回授权，恢复前需要完全退出酷狗。

首次统一确认已在候选包中出现并产生有效授权记录；默认检测与恢复完整流程仍需继续验证。此前酷狗真实进度与歌词滚动已实测。尚未宣称所有客户端版本、暂停/切歌、人声逐句校时及真实安装文件恢复闭环均通过。不包含尚未实现的 Steam 状态分享、波点支持或其他规划功能。
