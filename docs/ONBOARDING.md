# 新手引导

本功能随 v1.2.0.0 交付，正式版与独立预览均使用同一套引导；预览的锁定说明会明确其隔离限制。

## 使用

首次展示在启动动画之后，共七步：播放控制、播放器选择、排版、字体与动效、单曲校时、锁定说明、帮助入口。
点击「上一步 / 下一步」切换，「跳过」或 Esc 结束；最后一步点击「开始使用」结束。
从「设置 → 关于与帮助 → 新手引导」可重新查看。

完成与跳过均记录 `onboardingDismissed: true`，纳入既有原生 preferences.json 保存队列，并有本机 WebView 存储回退。
此字段缺失时按首次展示处理，不迁移或重置已有字体、播放器、快捷键、歌曲偏移及缓存。
引导打开二级设置页用于定位，但不自动执行切歌、校时、应用预设或锁定；结束时恢复进入前的设置页。
暗区拦截点击，只放行当前高亮目标与说明卡片；Tab / Shift+Tab 在卡片按钮间循环，避免误触暗区。
预览配置仍与正式版隔离。

## 实现与验证

- `src/onboarding.js`：步骤、定位、键盘退出及生命周期。
- `src/onboarding.css`：局部高亮、页面暗化、说明卡片及强制颜色回退。
- `src/main.js`：真实控件与设置路由、配置持久化和引导期间的锁定保护。
- 不引入新依赖，不改动歌词会话或渲染器。
- 定位自动测试覆盖 640×280、640×360、1080×600 与 1920×1080；卡片空间不足时选择遮挡面积最小的位置，未承诺所有尺寸都零重叠。
- 已在原生 1080×600 窗口走过七步、Esc 退出并从设置重新打开，确认本机配置已写入。
- 最终包原生重启后未重复弹出；第 2 步点击暗区设置关闭按钮，设置与当前引导仍保持，未切走目标。
- 小窗口实际截图、屏幕阅读器及完整键盘操作仍需进一步人工验收；自动化位置测试不等于这些端到端验证。CUA 按 Tab 后的原生 AX 焦点仅报告文档根节点，不能据此认定完整键盘流程已通过。
