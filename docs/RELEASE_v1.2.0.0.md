# RiverXILee桌面歌词 v1.2.0.0

让音乐，留在看得见的地方。

这次更新，把重点放在三个日常体验上：界面更轻透，歌词获取更稳，播放控制更顺手。软件继续使用「RiverXILee桌面歌词」中文名称，发布者为 **RiverXILee**。

## 同版本界面替换 · 2026-11-08

本次重新构建并替换 v1.2.0.0 的安装版、文件夹 ZIP 与校验文件，版本号不变。

- 网易云增强控制的开启说明、二次风险提醒和恢复普通模式确认，统一为应用内液态玻璃面板，不再使用白底系统弹窗。
- 保留两次独立确认，默认焦点在取消；Esc、关闭、确认失效或未收到答复均不启用。
- 确认请求绑定当前窗口且只能回复一次，第一步同意不能代替第二步风险确认。

已安装旧构建 v1.2.0.0 的用户，需要重新下载覆盖安装；同版本不会再次触发版本更新提示。文件夹版请完整解压到新的文件夹，勿混用主程序与旧资源。此次确认流程改版的浏览器外观预览已获用户确认；已进行前端交互、后台确认通道测试和构建检查，不等同于重新执行真实播放器重启、完整安装或覆盖升级测试。

## 更轻透的玻璃界面

控制栏、设置面板、字体选择器与提示层统一采用新的玻璃材质。通过背景模糊、饱和度调整、轻白色叠层、细内亮边与克制的 RGB 折射，减轻厚重感和重影，同时保持文字与按钮清晰。

歌词区域依旧纯透明，不会额外铺设背景图。正式版不再显示「液态玻璃独立预览」标记，软件名称也不变。

## 外语歌曲，可以对照着看

新增可选的 **「原文＋平台译文」** 模式。开启后，平台已有的译文显示在对应原文下方，随同一行一起滚动，保留原文的高亮与时间轴。

- 开启位置：**设置 → 字体、颜色与动效 → 翻译模式**。
- 使用选中歌曲版本自带的译文，不需要密钥，也不产生额外机器翻译费用。
- 修复 QQ 音乐播放器有译文、桌面歌词却取不到的问题，并刷新旧版自动缓存中的空译文结果。
- 没有取得译文时继续显示原文；提示会区分「本次未取得」与「时间轴未对齐」，不再直接断言歌曲没有翻译。

此模式不是任意语言互译，译文是否存在、内容和语言取决于平台提供的歌词版本。

## QQ 音乐进度条，现在可以真正拖动

播放进度支持点击、拖动和键盘方向键调整。拖动时预览目标时间，松手后再执行跳转，歌词跟随播放器的实际进度更新。

QQ 音乐加入专用本地媒体控制适配，修复因系统能力标记不准确而禁用进度条的问题。操作前核对客户端和当前歌曲，操作后核对回传进度；拖动过程中切歌，会取消旧歌曲的操作。

该适配不需要把 BrimDeck 当中间层，不向 QQ 音乐注入代码，不修改客户端文件，也不读取账号凭据。

## 网易云：可选的临时进度增强控制

对未通过 Windows 媒体会话提供进度跳转的网易云客户端，增加 **设置 → 播放与同步 → 网易云进度增强控制**。功能默认关闭，不会自动记住开启状态。

- 开启前有两次独立确认，默认焦点均在取消按钮：先说明重启影响，再明确说明调试端口风险和关闭方式。
- 确认后临时重启网易云，通过其本机播放器控制页面发送跳转，并核对实际播放时钟；不修改 DLL、客户端文件、快捷方式或开机启动设置。
- 仅接受归属于网易云进程的本机回环端口；不提供任意调试脚本或账号数据读取接口。
- 通过「关闭并恢复普通模式」，或完全退出网易云后正常重开，关闭临时调试模式。

**重要安全提醒：**开启期间，同一电脑上的其他程序或网页可能通过调试端口访问、控制网易云内部页面及登录状态相关信息。退出桌面歌词本身不会关闭网易云的端口。只建议在信任当前电脑环境并理解风险时临时使用；不接受风险时请保持关闭，在网易云内调整进度。不同网易云版本可能不接受临时启动参数，失败不会改用修改客户端文件的方式。

其他音乐软件仍按其 Windows 媒体控制能力启用进度跳转，不支持的客户端不会显示假跳转。

## 少一些错配，少一些反复加载

- **同平台优先**：优先等待当前音乐平台的匹配结果，避免另一个歌词源只是返回更快，就抢占正确版本。
- **更严格的版本核对**：结合歌名、歌手、可用时长及 Live、翻唱、伴奏、加速等版本信息，减少同名不同录音的误配。
- **切歌恢复更平稳**：首次短暂失败先进行一次有上限的恢复，不立即闪出错误；后补歌曲 ID 可以触发重新获取，旧请求不会覆盖新歌曲。
- **临时错误有限重试**：对 503 等服务异常增加重试与冷却，减少请求风暴；限流、持续失败及无匹配结果仍会明确告知。
- **缓存扩展到 1000 首**：保护手动绑定，旧版自动匹配按新规则重新校验，不必手动清空全部缓存。
- **明确纯音乐不再反复找词**：识别平台声明或明确伴奏标记；也可手动将本首设为纯音乐。空响应和网络错误不会被当成纯音乐。

在线服务的可用性和平台版权情况不由本软件控制，本次改进不代表所有歌曲都能保证取得歌词。

## 第一次打开，也能很快上手

新增七步引导，围绕真实控件说明播放控制、歌词设置、同步与锁定等操作。支持上一步、下一步、跳过及 Esc 退出，完成或跳过后会记住；可从 **设置 → 关于与帮助 → 新手引导** 重新查看。

同时保留二级设置、自定义或清除快捷键、字体选择、1～5 行歌词、显示方案备份与原有鼠标穿透功能。

## 下载与升级

- **安装版 `x64-setup.exe`**：使用 RiverXILee 自定义安装中心；原安装版用户可使用应用内更新，或下载后覆盖安装。
- **文件夹版 `x64-folder.zip`**：免安装，必须完整解压后运行主程序。保持文件夹版的用户，请下载完整 ZIP 更新，不要只替换 EXE；应用内更新目前仍使用安装包。
- **`SHA256SUMS.txt`**：用于核验下载文件完整性。
- **`LICENSE` / `THIRD_PARTY_NOTICES.txt`**：项目许可与第三方依赖声明。

升级前请从托盘完全退出旧版。应用标识和正式版用户配置目录保持不变，继续读取原有窗口位置、显示设置、快捷键、单曲偏移、歌词缓存和显示方案。此前的独立预览使用单独配置目录，其设置不会自动迁入正式版；显示方案可通过导出、导入迁移。

对外版本为 **1.2.0.0**；为兼容 Cargo/Tauri 的版本格式，内部构建和部分 Windows 文字属性显示 **1.2.0**，两者属于同一个版本。
