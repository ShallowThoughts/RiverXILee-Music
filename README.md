# RiverXILee桌面歌词 v1.1.3

一个为 Windows 设计的沉浸式透明多平台桌面歌词工具。RiverXILee桌面歌词通过 Windows 系统媒体会话识别当前正在播放的歌曲、播放状态和时间轴，再自动匹配在线歌词，无需本地音频。

## 下载

- [查看历史版本与更新说明](https://github.com/ShallowThoughts/RiverXILee-Music/releases)

v1.1.3 已补发更新器修正版：修复下载受 12 秒总超时限制的问题，增加自动重试和中文错误提示。已安装早期 v1.1.3 的用户需手动下载并覆盖安装一次；版本号不变，不会弹出同版本更新提醒。升级前请从托盘完全退出旧程序。

## 使用方法

1. 打开音乐平台并播放任意在线歌曲。
2. 启动“RiverXILee桌面歌词”。无需开启播放器自带的桌面歌词。
3. 鼠标移入窗口底部即可显示控制条。
4. 点击图钉切换置顶，点击四角图标切换全屏。
5. 点击锁图标后窗口会鼠标穿透；默认按 `Ctrl + Shift + L` 解锁，也可以在设置中自定义。
6. 关闭主窗口后软件继续驻留系统托盘，可从托盘重新显示或完全退出。

## 游戏中显示

窗口化和无边框全屏游戏可以正常显示置顶歌词。少数使用独占全屏的游戏会覆盖普通桌面窗口，请把游戏显示模式改为“无边框”。应用不向游戏进程注入代码。

## 能力

- 仅识别音乐客户端白名单中的 Windows 媒体会话，未知来源默认忽略
- 支持 QQ 音乐、网易云音乐、酷狗音乐、酷我音乐、汽水音乐、Spotify、Apple Music 等主流音乐客户端
- 自动忽略抖音、哔哩哔哩、浏览器及普通视频播放器，避免视频时间轴抢占或卡住歌词同步
- 同步播放、暂停和实时时间轴
- 网易云音乐优先使用当前歌曲 ID 对应的网易云原生歌词与播放时钟；ID 暂时缺失时按歌名、歌手和时长在网易云内继续匹配
- 其他音乐平台使用歌名、歌手、专辑和时长严格匹配在线 LRC 歌词
- 歌词获取失败时自动重试，并拒绝错误歌手或时长明显不同的版本
- 支持中文、英文、韩文等多语言歌曲；自动处理 `(Single Version)`、`(Remastered)` 等版本标签与括号信息
- QQ 音乐与网易云音乐同时打开时，根据真实播放进度自动切换歌词，不再被空闲的旧媒体会话占用
- 可以锁定指定音乐平台，也可以随时切回自动选择
- 歌词版本不正确时，可以在软件内查看网易云与 QQ 音乐候选结果并手动选择
- 每首歌曲可独立设置歌词提前或延后，选择结果和偏移量都会自动记住
- 在线歌词获取成功后保存本地缓存，接口暂时不可用时仍可继续显示
- 未缓存歌曲自动联网取词；请求超时后持续退避重试，网络恢复可立即重试，快速切歌不会被旧请求覆盖
- 网易云备用识别优先核对实时窗口标题，首次播放的歌曲不再依赖已有播放历史；仍需要播放器提供有效的歌曲信息
- 同步设置可粘贴网易云或 QQ 音乐的完整歌曲链接，也可导入带时间标签的 LRC/YRC/QRC 文件，绑定到当前歌曲
- 支持保存、重命名和切换最多 20 个个人显示方案，JSON 备份可导入导出；导入时保留原有同名方案
- 上一首、播放/暂停、下一首控制
- 透明无边框窗口、始终置顶和全屏
- 2.65 秒透明启动动效：RGB 音频波形依次完成媒体会话连接、时间轴读取和歌词同步，再聚焦进入五行歌词
- 沉浸式五行布局：上两句、当前句、下两句
- 网易云优先读取真实逐字时间轴；普通 LRC 自动使用平滑逐句扫色
- 当前歌词可切换 RGB 流光或自定义纯色
- 透明设置面板可调 1～5 行、字号、行间距、上下位置和左右位置
- 支持取色器及 R/G/B 数值输入，显示设置自动保存
- 使用 DirectWrite 读取 Windows 已安装字体的完整家族名称，支持中文名、英文名搜索和样式预览，选中后应用；同时提供沉浸五行、纯净单行、双行字幕、游戏和直播显示预设
- 新增播放状态诊断，可查看播放器、歌曲、歌词来源、歌词格式、缓存状态和同步误差，并一键复制诊断信息
- 播放时间轴出现小幅误差时自动平滑纠偏，拖动进度或发生较大偏差时自动重新锁定
- 连续读取失败时自动重试，避免一次临时错误就清空正在显示的歌词
- 多显示器断开或原位置不可见时自动回到屏幕中央，也可以在状态页手动恢复位置
- 禁止重复运行多个实例；再次启动时会唤醒原窗口并提示软件已经在运行
- 窗口位置、窗口尺寸、显示配置、播放器选择、歌词偏移和自定义快捷键会持久保存，安装版与便携版均可恢复
- 启动后自动检查新版本，支持在应用内显示进度、直接下载并进行 SHA-256 完整性校验，无需打开 GitHub
- 更新检查与下载独立限时，下载总时限 10 分钟、单次停滞读取限时 45 秒；临时网络失败最多自动尝试 3 次，未校验的残留文件不会进入安装步骤
- 安装与更新使用统一的 RiverXILee 独立安装中心；全程只显示自有界面，后台静默覆盖旧版并保留配置，Windows 只保留最新版卸载项
- 换句时上浮、失焦与聚焦过渡
- 鼠标穿透锁定与全局快捷键解锁
- 支持自定义显示/隐藏、锁定/解锁、歌词提前、歌词延后、重新同步和切换播放器快捷键；被其他软件占用的组合会单独标红，其余快捷键仍然可用
- 单实例运行：重复启动会唤醒现有窗口，避免后台多开导致全局快捷键被旧实例占用
- 系统托盘、关闭到托盘和可选开机启动
- 适合明暗背景的歌词描边、阴影和逐行高亮
- 当前行未唱文字使用更清晰的轻描边，减少浅色背景上的灰块和模糊重影

## 问题反馈

软件设置面板内提供“问题反馈”入口，会自动附带当前版本、音乐平台、歌曲、播放进度、歌词匹配结果和时间偏移。也可以直接访问 [RiverXILee 反馈中心](https://riverxilee-feedback.riverxilee.chatgpt.site/)；提交后，查询信息会保存在当前浏览器，方便再次查看处理进度。

## 歌词补救与显示备份

- 在“同步 → 指定歌曲或导入歌词”中，粘贴网易云 `music.163.com/song?id=...` 或含 `songmid` 的 QQ 音乐完整歌曲链接，再点击“获取并绑定”。暂不支持平台短链接、歌单或专辑链接。
- 也可以导入不超过 2 MB 的 LRC、YRC 或 QRC，支持 UTF-8 与常见中文编码；纯文本无时间标签的歌词不能同步滚动。
- 绑定结果保存在歌词缓存中；清空缓存或点击“恢复自动匹配”后会重新搜索。
- 在“显示 → 我的显示方案”保存当前字体、颜色、行数、间距、位置与动效。导出备份包含当前样式与个人方案；导入会恢复样式并合并方案，最多 20 个，重名但内容不同的方案会另存为新名称。
- 自定义字体仍需安装在目标电脑上，备份不打包字体文件。

## 开发与构建

```powershell
npm install
npm test
npm run tauri dev
npm run tauri build
```

运行环境为 Windows 10/11，使用 Tauri 2、Rust 和原生 Windows GSMTC 媒体接口。受支持的音乐客户端需要向 Windows 提供媒体会话、歌曲信息和时间轴；浏览器网页和未列入白名单的播放器不会参与同步。
