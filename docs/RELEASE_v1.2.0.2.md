# RiverXILee桌面歌词 v1.2.0.2

Windows 正式版 · 2026-11-25 · GPL-3.0-only

这次更新重点完善播放器连接、歌词同步和升级后的使用体验。

## 升级后，先看看这次更新了什么

新增版本更新日志弹窗：每次升级后首次启动自动展示，同一版本关闭后不再重复提醒。首次安装也会展示一次，后续可在「关于与帮助 → 更新日志」随时重看。

已读记录与原有配置一起保存，不清空字体、窗口位置、快捷键、歌词缓存和手动选择的歌曲版本。版本比较按数字处理，降级时不自动重复弹出。

## 增强功能，首次确认后默认启用

首次启动先统一说明网易云增强与酷狗增强的用途及风险。只有明确点击「同意并进入」才进入主界面；「退出应用」、Esc 或关闭提示会退出，不默认同意。

授权后自动检测播放器。设置页移除两项增强的手动开启按钮，保留当前状态；未运行的播放器不强行启动。酷狗若尚未准备且正在运行，会提示先正常退出，不强杀进程。自动检测失败不循环重启或反复修改文件。

托盘保留「关闭增强并恢复」，方便撤回授权、恢复客户端并退出。

## 修复酷狗歌词能显示却不滚动

修复了部分酷狗版本由安装根目录启动器持有进度端口，却被误判而无法读取真实进度的问题。继续保留安装路径、进程身份和回环地址校验，不通过放宽到任意进程来解决兼容问题。

已在实播场景观察到真实进度推进和歌词正常换行。没有有效时间轴时，不再从零计时冒充同步。酷狗进度拖拽暂不支持。

## 歌词来源更明确

QQ、网易云和酷狗各自使用本平台歌词，不在失败后自动切换其他音乐平台。候选取词和缓存也检查来源，并结合歌手、时长及录音版本减少错配；本地导入与手动纯音乐标记保留。

## 使用前请了解

增强会开放播放器本机调试端口，本机其他程序或网页可能访问其内部页面；网易云增强会临时重启客户端。酷狗增强还需备份并修改内核文件，原数字签名会失效。退出桌面歌词不会自动关闭仍运行的播放器端口或恢复酷狗文件，请通过托盘恢复入口撤回；恢复前需完全退出酷狗。

兼容性说明：酷狗已在实播场景验证真实进度与歌词换行；不同客户端版本、暂停/切歌、逐句听感校时及完整恢复流程可能仍存在兼容差异。未知内核、文件冲突或权限不足会停止自动处理并保留恢复资料，不承诺所有版本均可用。Steam 状态分享、波点等未验证或规划功能不包含在本次发布中。
