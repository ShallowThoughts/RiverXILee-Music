# RiverXILee桌面歌词：液态玻璃独立预览

这是 v1.2.0.0 本地候选，不是新版正式发布。不覆盖已安装正式版，不进入更新通道。
请完整解压 ZIP，运行其中的 RiverXILee-LiquidGlass-Preview.exe。

本文仅说明独立预览构建。玻璃材质与本轮功能已合入 v1.2.0.0 正式构建；正式版仍叫「RiverXILee桌面歌词」，不带预览字样，也不使用这里的隔离限制。发布内容以 RELEASE_v1.2.0.0.md 为准。

落地规则：暗色半透明胶囊、焦点模糊、位移折射和克制的 RGB 分离。
按这次用户提供的教程改为 18px 背景模糊、1.65 饱和度、10% 白色叠层与 1px 内亮边；保留暗色可读性底色，不给透明歌词区铺背景。
SVG 折射减弱为 48 / 44 / 40 三通道，取消移位原图叠加以减少重影，保留 0.5 末级模糊。
折射图随控件尺寸与圆角更新并缓存，不逐帧生成。
文字和操作控件不经过该滤镜，避免跟着背景模糊。

## 本版范围

- 主控制栏、二级设置、字体选择器、更新提示与短提示统一玻璃材质。
- 保留纯透明歌词区域、彩色进度线与既有歌词功能。
- 使用单独的预览应用标识和配置目录，可以与正式版区分。
- 不注册全局快捷键、不修改开机启动、不接管正式更新。
- 为避免没有解锁快捷键时误锁窗口，设计预览暂不启用鼠标穿透锁定。
- 对外版本为 1.2.0.0，Cargo/Tauri 内部构建版本为 1.2.0；不代表正式版已发布。
- 系统要求减少透明度或强制颜色时，不使用折射滤镜。
- 新增七步新手引导：高亮真实控件，支持上一步、下一步、跳过和 Esc 退出。
- 引导完成或跳过后保存在本机，下次启动不重复弹出；可从「设置 → 关于与帮助 → 新手引导」重新查看。
- 引导不会自动切歌、修改歌词样式或开启鼠标穿透锁定。
- 自动缓存扩展到 1000 首，手动绑定不随自动缓存淘汰；保留同平台优先和更严格的录音版本校验。
- 503 等临时错误改为有限重试与冷却，明确纯音乐停止自动查词；未标注的纯音乐也可在「播放与同步 → 指定歌曲或导入歌词」中手动标记。
- 切歌首次短暂失败先进行一次有上限恢复，不立即显示错误；持续失败仍正常告知。
- 「字体、颜色与动效 → 翻译模式」支持原文与平台已有译文对照。无可对齐译文时只保留原文，不另接机器翻译。
- QQ 译文改用同一 songMID 的公开网页接口，旧版空译文自动缓存在双语模式下重新获取；本次未取得译文不再误报为平台没有翻译。
- 播放进度支持点击、拖动与键盘方向键。QQ 音乐使用其自带的本地媒体管道，核验管道所属 QQMusic.exe、当前歌曲及跳转后返回的进度，不再仅依据不准确的 SMTC 能力标记禁用操作；其他播放器继续使用系统媒体跳转能力。拖动中切歌会取消本次跳转，不修改歌词偏移。
- QQ 本地控制连接使用 RiverXILee 自己的应用身份，仅在用户跳转时短暂连接，有超时与消息大小上限；不注入、不修改客户端文件、不读取账号凭据。协议参考 [BrimDeck 的 QQ 适配源码](https://github.com/MoFeng2223/BrimDeck/blob/main/src/BrimDeck/Native/QqMediaConnection.cs)，本项目独立实现。

## 真实能力边界

这是 WebView2 内的 SVG / CSS 材质实现，不是 Apple 平台原生 Liquid Glass。
界面内背景可参与折射；不能据此承诺 Windows 桌面上其他程序也会实时被折射。
不采集桌面、不截取其他程序画面来制造效果，也不因此要求屏幕录制权限。
原生窗口外部的实时折射需要另行设计和验证。

## 查看与返回正式版

鼠标移入窗口底部查看控制栏，点击设置检查二级页面和字体列表。
确认效果后再决定是否纳入未来版本；不要上传为正式版或替换现有安装。
从预览版托盘选择“退出”即可关闭；正式版安装和配置不做迁移。

开发构建：运行 scripts/build-glass-preview.ps1。
浏览器调试可在开发地址后添加 ?glass=1，仅用于预览，不改变正式构建。
