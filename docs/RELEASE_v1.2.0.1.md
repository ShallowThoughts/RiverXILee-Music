# RiverXILee桌面歌词 v1.2.0.1

让歌词跟对版本，也跟上此刻。

这次没有大改界面，而是集中处理大家更常遇到的问题：自动匹配不准确、切歌后仍沿用旧结果，以及需要反复手动选择歌词。软件名称继续为「RiverXILee桌面歌词」，发布者 RiverXILee。

## 同平台优先，不再让备用来源抢跑

- 使用 QQ 音乐时优先查 QQ，使用网易云时优先查网易云。
- 等待主平台有时限的查询完成，主源失败、超时或没有匹配结果时再考虑备用来源，不再只因备用源返回更快就选用。
- QQ 播放时的网易云备用歌词还需核对完整歌名、歌手和时长；信息不足或录音版本不一致时，不随便套用同名歌词。

## 不只看歌名，还要核对是谁唱的

- 结合歌名、歌手、时长和录音版本筛选，合格候选里优先选择时长更接近的版本。
- 改善中英文歌手别名、多人合唱顺序、平台完整标题别名和 Single Version 标签差异的处理。
- 继续区分 Live、伴奏、加速、翻唱等录音标记；不把歌名或歌手名字的局部相同当成准确匹配。
- 这里读取的是播放器提供的歌曲信息，不是通过声音识别歌手，也不是音频转写。

## 网易云歌曲 ID 晚到，也会自动纠正

- 先搜索后收到准确歌曲 ID 时，自动重新获取对应版本，而不是一直沿用先前的自动结果。
- 旧自动请求晚返回不能覆盖准确 ID 的新结果；原生 ID 首次短时请求失败后，仍在总预算内保留该 ID 重试。
- 已知准确 ID 时，不复用另一歌曲或另一歌词源的自动缓存。旧自动匹配会按新规则重新校验，无需手动清空全部缓存。
- 用户主动选择、导入的绑定继续保留；自动纠正不会打断正在进行的手动绑定。

## 播放进度对齐更稳

- 修正慢速媒体请求的前端计时锚点，避免把请求发起时间误当作收到播放进度的时间。
- 后端采样时间跟随实际时间轴读取，减少读取延迟带入位置计算。
- 切歌先恢复新歌曲自己的校时偏移，不沿用上一首的偏移；播放速度变化时立即重新对齐。

## 下载与升级

- **安装版 `x64-setup.exe`**：使用 RiverXILee 自定义安装中心；从托盘完全退出旧版后覆盖安装。原安装版也可使用应用内更新，网络仍需能访问 GitHub 的下载服务。
- **文件夹版 `x64-folder.zip`**：完整解压到新文件夹再运行，不要只替换 EXE 或混用旧资源。希望继续保持免安装方式的用户，请下载完整 ZIP；应用内更新目前仍使用安装包。
- **`SHA256SUMS.txt`**：校验下载完整性。项目与第三方许可见 `LICENSE`、`THIRD_PARTY_NOTICES.txt`。

应用标识和配置目录保持不变，继续保留原有窗口位置、字体、显示方案、快捷键及手动绑定。对外显示 **1.2.0.1**；Cargo/Tauri 内部构建版本为 **1.2.1**，部分 Windows 文件属性也会显示这个三段版本。

## 验证与已知边界

- 已覆盖同平台优先、后补歌曲 ID、旧请求隔离、缓存校验、手动绑定保护、歌手别名与合唱顺序等自动化回归。
- 已执行网易云已报告歌曲与 QQ 五首多语种歌曲的在线取词回归；此前 QQ 的当前歌曲只读采样也完成过对照。这些不等于所有歌曲的人声同步、整曲或跨电脑验证。
- 安装包和完整 ZIP 均重新构建并校验资源完整性；本机不执行会覆盖现有安装的安装、升级或卸载操作。
- 在线接口可用性、平台版权和歌词时间标签仍受上游数据影响。平台只有静态文字时，不能伪造成同步歌词；普通逐句歌词的扫色也不代表真实逐字演唱时间。
- Alkam《Cry For Me feat. Ami》的截图反馈缺少准确歌曲 ID，尚未单曲复现，不将它写成已修复案例。
- 本版不包含未通过实测的波点音乐适配，Steam 动态歌词状态仍未实现。
- 暂无 Windows Authenticode 代码签名；GPL 许可和 SHA-256 校验不等于「已验证发布者」。

遇到问题可从「设置 → 播放状态」复制诊断信息，再通过软件内的问题反馈入口提交，方便区分播放器识别、歌词版本匹配和播放时间轴问题。
